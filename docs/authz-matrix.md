# API Authorization & Security Audit Matrix

Reviewed as part of Day 6 hardening across every registered Fastify route in `api/src/`.

## Global Security Invariants

1. **Identity comes exclusively from SEP-10 JWT `sub`:** `authFastifyPlugin` (`src/plugins/auth.ts`) verifies `Authorization: Bearer <token>` using `JWT_SECRET` and populates `request.user = { address: payload.sub }`. No route ever trusts a Stellar address passed in a request body or query parameter to establish caller identity.
2. **Indexed chain tables are read-only to HTTP routes:** `HelpRequest` (financial columns), `Milestone`, `Contribution`, `Giveaway`, `GiveawayClaim`, `ReputationEvent`, and `Attestation` are mutated exclusively by `src/indexer/`. The only off-chain annotation on `HelpRequest` is `metadata` JSON (`POST /requests/:id/metadata`), which is creator-gated and verified against the immutable on-chain `contentHash`.
3. **Moderators can never touch funds:** Moderator endpoints (`src/modules/moderation/routes.ts`) only transition `Report.status`, record `ModerationAuditLog` rows, and toggle off-chain content visibility (`Post.status = HIDDEN`, `Comment.status = HIDDEN`, `HelpRequest.metadata.hidden = true`). Zero contract invocations or balance mutations exist in moderation code.
4. **Defense-in-depth HTTP controls:**
   - `@fastify/helmet` security headers (`src/plugins/helmet.ts`)
   - Strict CORS origin allowlist (`CORS_ORIGINS`, `src/plugins/cors.ts`)
   - Global 1 MiB JSON body limit (`bodyLimit: 1_048_576` in `src/app.ts`; `8 MiB` base64 envelope / `5 MiB` decoded binary cap + PNG/JPEG/WebP/GIF magic-byte sniffing on `POST /uploads`)
   - Global & social-write Redis rate limits (`120 req/min` anonymous IP, `300 req/min` authenticated address, stricter write buckets on posts/comments/uploads/reports/auth challenges)
   - Structured `pino` JSON logs with `x-request-id` correlation and secret/header redaction (`authorization`, `cookie`, `x-internal-token`, signing secrets).
